# Security-Tools-Dev

这是我个人开发的安全工具与脚本集合，用于辅助渗透测试与红队实战。

## 🛠️ 工具列表

### 1. Python 端口扫描器 (port_scanner.py)
- **功能**：基于多线程的 TCP 端口扫描器，可快速探测目标主机的开放端口。
- **技术栈**：Python `socket` 库 + `threading` 多线程。
- **用法**：`python port_scanner.py`（默认扫描 127.0.0.1 的 1-1024 端口）
